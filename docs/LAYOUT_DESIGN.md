# カードの並びと間隔調整

複数の枝を展開してコードを読む用途では、所属とソース順を固定する方針を採用した。「どこへ移ったか」を探し直す負担を減らすための設計判断であり、利用者調査による最適性の証明ではない。

以前は所属・呼び出し・継承をまとめて有向グラフとして扱い、循環をまとめ、関係元の平均位置と名前から上下順を決めていた。線の交差を抑える狙いはあるが、展開で関係線が増えると列と上下順が変わり、所属を追いづらくなる。

## 構造図のルール

| 観点 | 配置 |
| --- | --- |
| 左から右の列 | 所属階層の深さで固定 |
| 上下のまとまり | 同じ親の子孫を連続した帯にまとめる |
| フォルダ・ファイル | フォルダを先にし、それぞれ自然な名前順（v2、v10） |
| 定義 | ソースの行順 |
| 引数 | 宣言順 |
| 親 | 子孫の帯の中央へ揃える |
| 呼び出し・継承線 | 構造の配置を動かさず重ねて描画 |

上下順は実行順ではない。上の枝を展開すると必要な高さの分だけ下の枝は移動するが、兄弟順と枝のまとまりは維持する。操作したカードの画面内の注目位置も引き続き保持する。

所属線のない純粋な関係グラフでは、従来の循環をまとめるレイアウトを使う。重複・複数親・循環を含む所属線でも、無限再帰やカードの重複配置を起こさないようにする。

## 操作

縦間隔は152〜640px、横間隔は292〜900px。カード自身の高さ128px・幅244pxを含む基準位置の距離で、初期値は縦168px・横338px。拡大率とは独立し、設定値は次回も復元する。

調整パネルの文字・数値は選択できない。ラベル・数値・余白からのドラッグはキャンバス全体の移動、スライダー上は間隔調整として扱う。

モデルの検証は `tests/graph-model.test.cjs`、実マウス操作の検証は `tests/layout-controls.smoke.cjs` に置く。呼び出し線変更時の位置不変、枝の連続性、ソース順、横間隔の反映、設定復元、パンとrange入力の分離を確認する。

実施結果：JavaScript 35件とブラウザ4種類が成功。画面画像でも枝のまとまりと2段の調整パネルを確認した。
